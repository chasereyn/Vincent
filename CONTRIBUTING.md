# Contributing

Vincent is a personal tool, built for one person's review workflow. Its
design decisions — what it does and does not do — are personal choices,
recorded in `CLAUDE.md`. They are not up for debate in a pull request.

**Pull requests are closed automatically**, unread, by
`.github/workflows/close-prs.yml`. This is not personal; it saves both of
us the time of a review that was never going to end in a merge.

**Bug reports are welcome.** Open an issue with a screenshot and the
output of `vincent --version`.

**Forks are welcome.** Vincent is MIT-licensed — see `LICENSE` — so take
it and make it yours.
